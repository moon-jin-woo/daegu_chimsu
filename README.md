# DALFLOOD LAB — 대구 달서구 기온상승·침수 시나리오 웹사이트

OpenStreetMap 위에 8개 관측 지점을 표시하고, 실제 공개 지형 고도자료를 읽은 다음 강우 시나리오에 따른 지표수의 이동을 간단하게 탐색하는 정적 웹 앱입니다.

**중요:** 이것은 연구·교육용 **지형성 유출 민감도 분석** 도구입니다. 공식 홍수예보, 정밀 도시침수 수리모형, 실제 위험등급 또는 대피정보가 아닙니다. 현실의 피해·대피 판단에 사용하지 마세요.

## 사용법

로컬 실행 (브라우저에서 HTML 파일을 직접 여는 대신 HTTP 서버를 실행해야 합니다):

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Node.js 20 이상에서 `npm test`로 계산 로직을 검증할 수 있습니다.

GitHub Pages: Settings → Pages → Build and deployment → **Source: GitHub Actions**를 선택합니다. `main` 브랜치 푸시 시 검증 및 Pages 배포 Workflow가 실행됩니다. **배포가 성공했는지 Actions에서 확인해야 하며, 처음부터 공개 URL이 작동하는 것으로 가정하면 안 됩니다.**

## 기능

- OpenStreetMap 위에 지정 8개 지점의 원형 마커와 레이블, 상세 팝업 표시
- 기온 상승량(0~5°C), 시간당 강우량(10~200 mm/h), 강우 지속시간(1~6시간), 강우강도 온도 민감도(0~12%/°C), 일률 손실량(0~100 mm/h), 침수심 판정 기준(0.05~0.5m) 설정
- 공개 Mapzen Terrain Tiles (Terrarium PNG)를 AWS 데이터셋에서 받아 약 220×180 격자에서 계산
- 60초 간격 단순화 확산파 근사계산, 15분별 수심 지도, 시간 슬라이더
- 선택한 수심 기준 이상인 격자는 반투명 파란색, 해당 대표 지점은 빨간색, 나머지는 흰색
- 침수 판정 지점 수, 최대 격자 수심, 격자 기준 침수 면적 표시
- OSM Nominatim 지오코딩(사용자 명시적 요청 시 순차 호출), 마커 드래그 좌표 보정 및 브라우저 저장
- 고도자료를 다운로드하지 못하면 임의의 결과를 생성하지 않고 재시도 안내

## 8개 관측 위치

1. 대건고등학교
2. 월성편한세상 — `e편한세상월배`와 동일 지점인지 확인 필요
3. 학산 정상 — **실제 최고점 좌표 미확정**
4. 대원고등학교 — **달서구가 아닌 달성군 화원읍**
5. 월광수변공원 — **도원지 등 기존 수역과 신규 침수를 구분하지 못함**
6. 계명대학교 — 성서캠퍼스 기준
7. 와룡산 — **정상 좌표 미확정**
8. 장동초등학교

**초기 마커 좌표는 미검증 잠정값**입니다. 자동 OSM 검색 또한 시설 중심/대표점일 수 있으며 산 정상은 자동 검색대상에서 제외했습니다. 지도에서 직접 좌표를 확인하고 필요하면 마커를 이동시키세요. 지점별 수심은 부지 전체가 아니라 **격자 하나의 대표값**입니다.

## 계산 정의 및 한계

- 기온 상승에 따른 강우강도는 `I = I0 × (1 + α/100)^ΔT`로 계산하며 기본 α=7%/°C는 **임의 시나리오 가정**입니다. 포화수증기압 변화율이 지역 집중호우 강도 변화율과 동일하다는 뜻이 아닙니다. 실제 미래기후 분석은 기상청 SSP 극한강우 예측 및 관측 강우 자료를 사용해야 합니다.
- DEM은 Mapzen/Terrain Tiles의 여러 지형 원자료를 Web Mercator 타일로 인코딩한 것입니다. 위치별 수직 정확도 및 지표면 피복 영향이 다를 수 있습니다. 화면 격자 크기(약 90m)는 실제 도로나 교내 저지대 같은 미시 지형을 설명할 수 없습니다.
- 유입수량은 `max(0, 강우강도 - 일률 침투·배수 손실)`로 매우 단순화되어 있습니다. 토지피복, 하수관거, 맨홀, 펌프, 건물, 하천 수위, 월류, 도원지 수위/방류, 실시간 침수흔적이 반영되지 않습니다.
- 4방향 총수두(고도+수심) 차이로 Manning 계수를 사용한 흐름을 근사하고, 격자 유출량을 가용 수심으로 제한해 수심이 음수가 되지 않도록 합니다. 가장자리는 외부 유출 경계로 두었습니다. **검증된 2차원 천수방정식 또는 1D/2D 연계 수리모형이 아니며** 침수시점·침수심의 정량적 정확도를 주장할 수 없습니다.
- 원래 물이 있는 저수지·하천을 별도 마스킹하지 않아, 파란색 영역이 신규 침수를 정확히 의미하지 않을 수 있습니다.

실제 재난 위험분석에는 고해상도 수문 지형 보정 DEM, 관거 및 저수지 자료, 하천 경계조건, 관측 강우 시계열, 과거 침수흔적 데이터, 공식 검증 가능한 2D/1D–2D 모델이 필요합니다.

## 파일

- `index.html`, `styles.css`: 반응형 웹 UI
- `src/app.js`: Leaflet 지도·제어판·관측지점·침수 오버레이
- `src/model.js`: 수치계산 핵심 및 격자 요약
- `src/terrain.js`: 실제 Mapzen Terrarium DEM 래스터 취득 및 재표본화
- `src/points.js`: 잠정 좌표 및 사용자 보정값
- `src/worker.js`: 계산을 UI와 분리한 Web Worker
- `tests/model.test.js`: 수학/좌표/수문 계산 단위시험
